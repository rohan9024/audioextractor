# Changelog

## 0.2.0

- Add real synchronous and asynchronous extraction APIs.
- Add cancellation-safe FFmpeg process-tree supervision.
- Add bounded per-extractor concurrency.
- Add ffprobe preflight inspection and audio-stream validation.
- Add input file-size and duration limits.
- Add atomic partial-file output and cleanup on failure.
- Add bounded stderr capture and machine-readable FFmpeg progress.
- Add structured result, metadata, progress, and exception types.
- Add CLI, integration tests, CI, examples, and benchmark scripts.
